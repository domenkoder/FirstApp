# FirstApp 📱

An Android application developed for learning Android development concepts, UI components, layout design, and user interaction in Android Studio.

## ✨ Features

- **Interactive UI Components**: Utilizes `Button`, `CheckBox`, `FloatingActionButton`, `TextView`, and `ConstraintLayout`.
- **Conditional Toast Display**:
  - **Checkbox Unchecked**: Displays a standard Android `Toast` at the default bottom position.
  - **Checkbox Checked**: Displays a custom-styled `Toast` centered on the screen.
- **Material Components & Snackbar**: Includes a Floating Action Button (FAB) that triggers a `Snackbar` message.
- **Edge-to-Edge Layout**: Adapts gracefully to modern Android display insets.

---

## 🛠️ Built With

- **Language**: Java 11
- **Platform**: Android SDK (Target SDK 37, Min SDK 29)
- **UI Framework**: AndroidX AppCompat & Material Components
- **Layout Manager**: ConstraintLayout

## 🚀 Getting Started

### Prerequisites

- [Android Studio](https://developer.android.com/studio) (2024.1 or newer recommended)
- Android SDK 29+ or an Android Emulator/Device running API level 29+

### Installation & Execution

1. **Clone the repository**:
   ```bash
   git clone https://github.com/your-username/FirstApp.git
   ```
2. **Open in Android Studio**:
   - Select **File > Open...** and choose the `firstapp` project directory.
3. **Build & Run**:
   - Select your target emulator or physical device.
   - Click the **Run** button (`Shift` + `F10`) or deploy directly from Android Studio.
